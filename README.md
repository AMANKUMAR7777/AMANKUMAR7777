### Building now

**[SiftAI](https://github.com/AMANKUMAR7777/SiftAI)** — a universal file organizer driven by local
LLM models. It reads your downloads, photos and documents, proposes a structure, and never deletes
anything without a copy. Python, local inference, no cloud round trip.
